Для артистов

Публикуйте и лицензируйте свою музыку

Sonara Pack позволяет артистам строить публичный каталог пакетов и треков с превью, лицензиями и страницами, доступными для поиска. Платформа сейчас находится в Pre-V1: функции, доступные сегодня, чётко отделены от коммерческих функций, запланированных для V1.

Артисты могут публиковать пакеты и треки через текущий процесс, готовить лицензию, добавлять сведения каталога и получать публичные страницы для релизов. Опубликованный контент автоматически наполняет каталог, внутренние ссылки и существующие SEO-системы.

Развивать видимость

Каждая публичная публикация может стать точкой входа к артисту: страница пакета, подходящие страницы треков, релевантные категории, sitemap и публичные изображения. Цель — чтобы поверхность обнаружения росла вместе с каталогом без ручной SEO-операции для каждого релиза.

Свобода распространения

Текущий процесс Sonara Pack не делает публикацию эксклюзивной для платформы. Артист остаётся ответственным за свои права и может продолжать использовать музыку в других местах, если это не конфликтует с выданными лицензиями.

Запланировано для V1 / позже

Запланировано для V1 / позже

Реальные платежи, коммерческий checkout и связанный доход остаются отключёнными в Pre-V1. Текущая планируемая коммерческая модель основана на комиссии Sonara Pack, при этом артист сохраняет большую часть дохода от продажи. Окончательные условия должны быть ясно представлены при активации коммерческого режима.

Запланированы дополнительные ресурсы

Архитектура также предусматривает типы контента V1, такие как MIDI-файлы и некоторые проекты DAW. Их не следует воспринимать как коммерческие продукты, уже активные сегодня.

Создавать основу до коммерциализации

Pre-V1 используется для подготовки каталога, видимости, привычек публикации и платформы до запуска реальных платежей. Артист может уже сейчас строить своё присутствие без заявления Sonara о том, что продажи V1 уже доступны.
